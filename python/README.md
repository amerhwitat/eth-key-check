# Python implementation

This directory is the Python reference implementation for the Chimera Crypto stack.

It contains the existing scanner, database, deterministic verification, ML/RL research, and Python GUI modules. The Python implementation remains the reference behavior for cross-language conformance.

Security boundary: recovery operates only on recovery material already possessed by the operator. No address-to-private-key guessing, seed cracking, or arbitrary private-key enumeration is implemented.
