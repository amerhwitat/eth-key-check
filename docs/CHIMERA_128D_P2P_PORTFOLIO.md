# Chimera 128D + P2P Portfolio Integration

This repository participates in Chimera interoperability only for authorized cryptographic research metadata, public/synthetic vectors, validation results and provenance.

The 128D semantic layer can represent workload geometry/topology, time, observer perspective, events, objects, properties and extensible analytical vectors. The P2P envelope is authenticated and opt-in, with identity/capability validation, sequencing, payload hashing, replay protection and optional signatures.

P2P must never be used to distribute private keys or seed phrases, coordinate unauthorized cracking, harvest credentials, scan targets without authorization, transfer arbitrary executables or invoke remote commands.

Python, Node.js, Java and C++ implementations remain native while sharing deterministic JSON/JSONL contracts.

Original project code is GPLv3-or-later; crypto libraries and other third-party components retain their upstream licenses.
