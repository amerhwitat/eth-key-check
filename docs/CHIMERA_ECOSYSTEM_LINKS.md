# Chimera II OS Ecosystem Links

Canonical portfolio: [ChimeraIIOS](https://github.com/amerhwitat/ChimeraIIOS) · [Complete repository portfolio](https://github.com/amerhwitat/ChimeraIIOS/blob/main/docs/CHIMERA_ECOSYSTEM_PORTFOLIO.md) · [Public web portal](https://amerhwitat.github.io/chimera/).

`eth-key-check` is the safe Ethereum interoperability component: private-key-to-address derivation for material already possessed by the operator, address validation and EIP-55 checksum handling.

Crypto scope remains defensive/interoperability only; no public-address-to-private-key recovery is implemented.
